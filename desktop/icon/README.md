# The CBCTScope icon

The mark is a scope: a ring with one cut, and in the cut a single point, the reader let in.
It is drawn in the viewer's own amber on near-black, the colours of the reading screen, and holds its shape from the Dock down to a 16 px browser tab.
It deliberately avoids the category's habits: no tooth, skull, medical cross, X-ray arcs or the letters "3D", and none of the blues and teals most dental and radiology software wears.
`cbctscope.svg` is the only source (macOS grid: the 824 px tile centred on a 1024 canvas); `npm run icon` renders `icon.png`, `icon.icns`, `icon.ico`, `app/icon.svg` and `app/apple-icon.png` from it, and `npm run icon -- other.svg` drops in a new mark.
